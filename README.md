# Landing Page - Tech Day El Salvador 2026

Landing page oficial para la presentación **"Más allá de la IA: Lo que seguirá marcando la diferencia"**, impartida por Mario López (B2B Cloud And Cybersecurity Chief en Tigo Business) durante el Tech Day El Salvador 2026.

Este proyecto sirve como un hub centralizado de recursos, rutas de aprendizaje y certificaciones oficiales (Microsoft, Google Cloud, AWS y Platzi) para que los asistentes al evento puedan continuar su desarrollo en Inteligencia Artificial con un enfoque corporativo y de transformación de negocio B2B.

## 🚀 Características

* **Diseño Responsivo:** Interfaz adaptable a dispositivos móviles, tablets y escritorio utilizando el sistema de grillas de Bootstrap 5.
* **Organización por Pestañas (Tabs):** Navegación fluida entre diferentes proveedores de nube y plataformas de educación para categorizar los recursos de IA.
* **Estilización Corporativa:** Implementación de paleta de colores personalizada y componentes visuales modernos adaptados a la identidad gráfica del evento.
* **Optimización de Medios:** Tratamiento avanzado de imágenes mediante CSS puro (`aspect-ratio` y `object-fit`) para garantizar que la fotografía del ponente mantenga proporciones profesionales de retrato independientemente de la resolución original de origen.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura base y semántica del sitio.
* **CSS3 (Custom):** Reglas específicas para el branding, efectos hover, y manipulación del DOM visual.
* **Bootstrap 5.3.2:** Framework frontend para agilizar el diseño UI/UX mediante componentes preconstruidos.
